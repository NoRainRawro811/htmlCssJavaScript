What CSS Is

CSS is a styling language, not a programming language. HTML is for the content of a page. CSS is for how that content looks.

CSS Syntax

A rule starts with a selector, then curly brackets. Inside the brackets are property: value pairs, each ending with a semicolon. Example: h1 { color: blue; }

Selectors

Element selector: h1 picks every h1. Class selector: .intro picks every element with class="intro". Id selector: #main picks the one element with id="main".

An element can have many classes but only one id. An id should be used only once on a page.

No space (h1.big) means both at once. A space (div p) means inside. A comma (.big, .large) means share the same styles. The * selector picks everything.

Three Ways to Add CSS

Worst: inline, with a style="" attribute. Middle: a style tag in the head. Best: a separate .css file connected with a link tag.

Which Style Wins

If two rules are equally strong, the one written last wins. Id beats class, and class beats element. Inline styles beat everything. Text color is inherited from the parent element.

Colors

Named: red. Hex: #0000ff (pairs for red, green, blue). RGB: rgb(255, 255, 0). RGBA adds transparency from 0 (see-through) to 1 (solid). HSL: hue, saturation, lightness.

Box Model and Units

From the inside out: content, padding, border, margin. Padding is space inside the border. Margin is space outside it.

px is a fixed size. % is a percent of the parent. em scales off the parent's font size. rem scales off the root font size.
